# playwright-qa-portfolio

Playwright + TypeScript QA automation framework – SauceDemo, TodoMVC and Conduit.

Phase 1 (MVP): SauceDemo UI E2E with Page Object Model – login, inventory, cart, checkout.
Phase 2 (v1.0): TodoMVC dynamic UI, Conduit UI + REST API.

Run tests:
npm install
npx playwright test
npx playwright show-report
